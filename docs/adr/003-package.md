# 003. Загрузка пакета

Сборка анализатора таргетирует `netstandard2.0` и компилируется против
Roslyn 4.8. Это разделяет версию SDK проекта (.NET 10) и версию API,
необходимую хосту анализатора. Компилятор и IDE предоставляют свои сборки
Roslyn. Пакет содержит DLL в `analyzers/dotnet/cs` и README.

Анализатор и MEF-провайдер исправлений находятся в одной сборке. Проверка
пакета собирает независимый проект через `PackageReference`, а тесты
вызывают провайдер в рабочей области Roslyn 4.8.
