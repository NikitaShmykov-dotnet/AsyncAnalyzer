# 001. Границы диагностик

AG001 опирается на символы BCL и ближайшую функцию. Проверяются
`Task` и `Task<T>`, включая унаследованные члены. Цепочка
`GetAwaiter().GetResult()` должна быть прямой. Это позволяет обнаруживать
блокирующий код без анализа потока данных.

Для AG002 исключаем функции с двумя параметрами по значению, где первый
имеет тип `object`, а второй — `EventArgs` или его наследник. Сходная
сигнатура обычного метода тоже будет исключена. События с нестандартными
делегатами могут потребовать локального подавления.

AG003 смотрит на уже выбранный метод и пропущенный аргумент по умолчанию.
Источник токена — единственный видимый параметр ближайшей функции.
Если токен передан явно, в том числе через `default`, правило не срабатывает.
